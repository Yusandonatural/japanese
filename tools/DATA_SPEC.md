# 用例データ仕様（荷札文法 / Tag Grammar）

サイトの目的：英語話者が14日で「助詞（荷札）つきの部品（荷物）を並べて文を組み立てる」力をつける。
用例は **実際の生活で使う自然な会話の一文** で、すべて次の JSON 構造に分解する。

## 文法モデル（必ず守る）

1. 文 = 荷物（chunks）+ 核（core）。核は必ず最後。
2. 荷物 = 名詞句（w）+ 荷札（p）。荷札は次の10枚だけ： は が を に で と へ から まで も 。荷札なし（p:""）は「時の副詞」か「裸の名詞（呼びかけ・注文など）」だけ。
3. 「の」「形容詞」「数量」は荷物の **内側** に含める（例: w:"友達の車", w:"新しいお茶", w:"お茶を二つ" は不可 → w:"お茶", 数量は core 側か別荷物に）。
4. **語尾は4つだけ（レベル1ルール）**：core の語尾は「〜ます／〜ますか／〜ません／〜ましょう」（名詞・形容詞は「〜です／〜ですか」）、依頼は「〜ください」。ました・でした・ね・よ・ましょうか は禁止（決まり文句 わかりました／ごちそうさまでした は例外）。
5. **過去・未来は時の副詞で補う**：tense が past/future の文は、role:"time" の荷物（昨日・さっき・もう・先週・明日・あとで・これから・来週 など）を必ず含む。
6. **疑問は「か」を付ける**：疑問文は question:true にし、core を「〜ますか／〜ですか／〜ませんか」にして ja は「？」で終える。語順は変えない。「何・どこ・誰・いつ・どう」は荷物として普通に置く（何を 買いますか？／どこで 買いますか？）。ましょう は「一緒に〜しよう」と誘う文だけに使い、英訳は Let's 〜 にする。
7. 平叙文の ja は「。」で終える。読点「、」は時の副詞の後などに入れてよい（検証時は無視される）。

## 1件のフォーマット

```json
{
  "id": "c03-041",
  "chapter": 3,
  "scene": "shopping",
  "ja": "明日、私は友達と奈良でお茶を買います。",
  "kana": "あした、わたしはともだちとならでおちゃをかいます。",
  "romaji": "Ashita, watashi wa tomodachi to Nara de ocha o kaimasu.",
  "en": "Tomorrow I'll buy tea in Nara with a friend.",
  "question": false,
  "tense": "future",
  "level": 2,
  "chunks": [
    {"w": "明日", "k": "あした", "p": "",   "role": "time",   "gloss": "tomorrow", "omit": true},
    {"w": "私",   "k": "わたし", "p": "は", "role": "topic",  "gloss": "I",        "omit": true},
    {"w": "友達", "k": "ともだち","p": "と", "role": "with",   "gloss": "friend",   "omit": true},
    {"w": "奈良", "k": "なら",   "p": "で", "role": "place",  "gloss": "Nara",     "omit": true},
    {"w": "お茶", "k": "おちゃ", "p": "を", "role": "target", "gloss": "tea",      "omit": false}
  ],
  "core": {"w": "買います", "k": "かいます", "gloss": "buy"},
  "fixedOrder": [],
  "focusParticles": ["を", "で"]
}
```

### フィールド規則

| フィールド | 規則 |
| --- | --- |
| id | `cNN-MMM`。NN=章（2桁）、MMM=配列内の連番（001から）。 |
| ja | chunks の (w+p) を順に連結 + core.w + 「。」or「？」と一致すること（「、」だけ自由）。 |
| kana | 全てひらがな（カタカナ語はカタカナのまま可）。chunks の (k+p) 連結 + core.k と一致。 |
| romaji | ヘボン式。長音は ō ū。助詞は wa / o / e と読む。 |
| en | 自然な英語。疑問文は「?」で終える。 |
| chunks[].p | 荷札。その章までに導入された荷札だけ使う（下表）。荷札なしは ""。w の末尾に助詞を含めない。 |
| chunks[].role | p に対応する role： は→topic が→doer を→target に→goal で→place と→with へ→toward から→from まで→until も→also。p:"" は time か bare。時刻・曜日など「三時に」「月曜日に」は p:"に", role:"time" にしてよい（time は例外的にどの荷札でも可）。 |
| chunks[].omit | 会話の文脈があれば言わなくても通じる荷物は true。文の答えの中心になる荷物（通常1つ）は false。 |
| core.w / core.k / core.gloss | 述語ひとかたまり。「お願いします」「ありがとう」「おはよう」のような決まり文句は core 単独の文として扱ってよい（chunks:[]）。 |
| tense | past / present / future。 |
| level | 1 = 荷物0〜1個・基本語彙、2 = 荷物2〜3個、3 = 荷物4〜5個か少し難しい語彙。 |
| fixedOrder | 順番を入れ替えてはいけない荷物のインデックス組。通常は []。「九時から 五時まで」のように順序固定なら [[0,1]]。 |
| focusParticles | この用例で学ぶ荷札（1〜2枚）。章の導入荷札を優先。 |
| context（任意、第8章以降で推奨） | `{"q_ja": "どこで かいますか？", "q_en": "Where will you buy it?"}`。この質問への返事としてこの文を見たとき、omit:false の荷物だけ残せば自然な返事になるように omit を設定する。 |

### 章ごとの制約

| 章 | 使える荷札 | 荷物の最大数 | 件数 | テーマ |
| --- | --- | --- | --- | --- |
| 1 | なし（p:"" のみ） | 2 | 150 | 核だけで話す。挨拶・決まり文句・「時の副詞＋核」「裸の名詞＋核」。時の副詞30語（昨日/さっき/もう/先週/今朝/明日/あとで/これから/来週/今晩/すぐ/今/今日/毎日/いつも/よく/ときどき/まだ など）を一通り登場させる。 |
| 2 | は が | 3 | 200 | 話題と主役。自己紹介・人やものの説明・「〜がある／いる」「〜が好き」。 |
| 3 | は が を に | 3 | 200 | 対象と行き先・相手・時刻。買い物・移動。 |
| 4 | は が を に で と | 4 | 200 | 場所・手段、相手・並列。食事・仕事。 |
| 5 | は が を に で と へ から まで | 4 | 200 | 方向・起点・終点、時間の幅。予定・移動。 |
| 6 | 全部（も を集中的に） | 4 | 200 | 追加「も」と、荷物内側の「の」（所属・つなぎ）。家・家族・持ち物。 |
| 7 | 全部 | 5 | 200 | 荷物を動かす練習用。荷物3〜5個の文を中心に、全場面から。 |
| 8 | 全部 | 5 | 200 | 省略の練習用。全件に context（質問）をつけ、omit を丁寧に設定。電話・仕事・食事の会話。 |
| 9 | 全部 | 5 | 200 | 飾りつきの荷物：形容詞（新しいお茶）、「の」（友達の車）、数量・色・大きさ。買い物・天気・畑。 |
| 10 | 全部 | 5 | 250 | 12場面の実際の会話を通しで。各場面20件前後、会話の流れ（質問→答え→次の発言）が見えるように並べる。level 3 中心。 |

### 場面（scene）の id

greeting, home, shopping, food, transport, time, work, farm, health, people, weather, phone
（farm は茶畑・田んぼ・直売所・古民家カフェの場面。「お茶を摘む」「草を取る」「稲を刈る」「店を開ける」など。）

### 語彙方針

- JLPT N5〜N4 相当の生活語彙に絞り、同じ語を違う荷札・違う位置で何度も再登場させる。
- 固有名詞は 奈良・京都・大阪・東京・日本・駅名程度。人名は使わない（私・友達・母・父・妻・夫・子ども・先生・店の人・同僚）。
- 「です」文は core を「〜です」にする（例: core.w:"学生です"）。名詞述語も core ひとかたまり。
- 同じ文（ja）を章内・章間で重複させない。

## 検証

`node tools/validate.js data/chNN.json` がエラーなしになるまで直す。
