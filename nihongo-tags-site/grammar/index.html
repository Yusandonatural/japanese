Tag Grammar

A Japanese sentence is tagged chunks + one core at the end. Learn the tags, and you can say the chunks in whatever order you like.

Five principles

  1. The core comes last. A sentence = chunks + core. The core alone can be a full sentence.
  2. A chunk = a noun phrase + a tag. The tag says who, what, where, when.
  3. Chunk order is free. Whatever you put first is what you're emphasizing.
  4. Chunks everyone already knows can be dropped.
  5. Decorations (adjectives, の) go inside a chunk, never as their own chunk.
